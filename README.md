# 古文整理 AncientTexts

这个仓库用于存放我个人整理的古籍原文、校注与参考资料，保持排版统一，方便后续同步到 GitHub 与跨设备查阅。

## 内容约定
- 每部典籍单独一个 Markdown 文件，文件名使用《书名》拼音或常用中文，便于检索。
- 开头以一级标题写书名，紧接着用引用块列出作者、版本、参阅资料等元信息。
- 正文采用符合原典的标点与字形，必要时通过脚注补充解释；引用他人评注要注明来源。
- 如需嵌入现代标注，可用加粗的「【说明】」语句或脚注，让正文与说明分层清晰。

### 推荐 Markdown 模板
```markdown
# 书名

> **【作者】**
> **【底本】**
> **【参阅】**

## 卷 / 篇名

正文……

[^1]: 注释或参考文献。
```

## 工作流（本地 → GitHub）
1. 在本目录新增或编辑对应的 Markdown 文件。
2. 使用 `git status` 检查变更，确认内容正确后 `git add <文件名>`。
3. 以简洁信息提交，例如 `git commit -m "Add Zhuangzi annotations"`。
4. 首次推送：`git remote add origin git@github.com:<用户名>/AncientTexts.git`，然后 `git push -u origin main`。
5. 后续同步只需 `git push origin main`，若在其他设备更新，先 `git pull --rebase`。
